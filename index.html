The fifteen tests

Each test asks for three separate outputs, v1 to v3. The model chooses the subject and style; the bar sets what each file must deliver.

Submit a run

Uploads go to inbox/. The Action files them into runs/ and rebuilds this dashboard within about a minute.

STEP 01

Pick the test

Use the test's slug, for example game-2d or idea. The slug is in the prompt header and on the tests page.

STEP 02

Name the file

The model writes its exact file name on its first line. If it did not, rename the file to this pattern:

{test}__{model}__{YYYY-MM-DD}__v1.html
STEP 03

Upload to inbox/

Each test gives three .html files: v1, v2, v3. Never a .rar. A retest starts at v4; existing runs are never overwritten.

STEP 04

Score it

Open a run and score its six axes. Ratings stay in this browser; use Export ratings to back them up or move them to another device. They are not published to GitHub.
