## Model prompt (send everything below this line)

Build an image studio as a single HTML file. There is **no external image or AI API**. Every picture must be generated by your code at runtime: canvas 2D, SVG, a WebGL fragment shader, or a mix. You may not embed image data, load image files, or call any service.

Produce **at least five distinct generated images**, each by a different technique. Choose the techniques and the subjects yourself. Examples of techniques you could use: noise-field terrain, flow fields, L-systems or recursive trees, a Truchet or tiling system, a ray-marched or signed-distance-field scene in a shader, a halftone or dithering pass over a procedural composition, a Voronoi or Delaunay mosaic, a reaction-diffusion pattern, a typographic poster built from code.

**Ground rules**
- You choose the name, look and subjects. Do not ask questions and do not hedge. Decide and build in one pass.
- One self-contained HTML file, no external files.
- Must run opened directly from disk (`file://`) and when hosted on GitHub Pages from a subfolder.
- No placeholder art, TODOs or dead controls.

**What the studio must do**
- A gallery with thumbnails of all the images. Each shows a title, the technique used, and the seed.
- Each image opens full size in a viewer.
- A **seed** input and a randomise button. Output must be reproducible: the same seed gives the same image. Use a seeded PRNG, never `Math.random`.
- At least **three parameter sliders per image** with a live re-render.
- A palette for each image, derived by your code (for example from a colour theory rule or a sampled gradient), shown as swatches.
- **Download PNG** for each image, via `canvas.toDataURL` or `toBlob`.
- A short note per image on what the technique is doing and what you would change next.

**Quality bar**
- Judge yourself on composition, colour, texture, and whether the outputs are surprising.
- Lay the images out deliberately. No generic gradient placeholders.

**Deliverable — naming is mandatory**
- Your file must be named exactly: `image__{model-slug}__{YYYY-MM-DD}__v1.html`
  - `{model-slug}`: your model name in lowercase, hyphens for spaces, dots kept when they are part of the name (for example `glm-5.3-flash`).
  - `{YYYY-MM-DD}`: today's date.
  - No creative file name, no uppercase letters, no spaces.
- Your first line is that exact file name. Then the complete file in one code block. After the block, five bullets on your key creative choices and one known limitation. Nothing else.
