# Prompt suite context

## Purpose
Own the thirteen canonical one-shot web-development briefs and the catalogue that drives dashboard labels, family grouping and ZIP intake validation.

## Suite structure
The suite is ordered by technology: Websites (01–03), HTML/CSS (04–06), JavaScript (07), Three.js (08), Visual/SVG (09–11), Applications (12) and Data (13). Each prompt is one challenge and one finished artifact. Games are intentionally outside this current web-development suite and can be added as a separate future expansion.

## Key files
- `catalog.json` — thirteen category slugs, titles, family labels, summaries and acceptance summaries.
- `01-*.md` through `13-*.md` — standalone prompts with automatic run identity, fixed version 1 and one-folder metadata contract.
- `README.md` — suite index, technology grouping, evaluation philosophy and submission process.

## Change and verify
Update catalog and prompt together. Keep `outputs_per_prompt` and every `min_outputs` at 1. Keep the family order and prompt numbering aligned with the actual technology progression. Preserve existing submissions, run history and organizer-owned ratings when reordering or adding prompts.
