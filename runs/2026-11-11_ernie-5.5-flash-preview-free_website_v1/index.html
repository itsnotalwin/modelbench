01

Statement

Umbra is a study in subtraction. Take away hue and what remains is value — the single variable that decides whether a form reads as solid, distant, soft or sharp.

Every plate on this site is drawn at runtime from a seed and a set of rules. Nothing is a photograph. Nothing is pre-rendered. The images exist only while you are looking at them.

Without colour the eye does the work: it reads density as weight, spacing as distance, grain as air. A halftone dot is not a grey pixel. It is a promise that the grey will be rebuilt by the viewer.

“A picture made of rules is not less authored than a picture made of paint. It is only authored earlier.”

    03

    Method

    Three rules, applied without exception.

    i

    One channel

    Every pixel is set to a single value between black and white. No hue, no tint, no colour-managed grey. If it cannot be written as one number, it is not in the picture.

    ii

    Seeded, not stored

    Each plate is a function of a seed, a clock and two parameters. Change the seed and you get another edition of the same rule. Nothing is cached and nothing is downloaded.

    iii

    Drawn, not loaded

    The site ships no image files. Every mark is a canvas operation: an arc, a line, a glyph, a thresholded pixel. The whole exhibition is a few kilobytes of code.

    04

    Colophon

    Type
    System grotesque and system monospace. No webfonts, no requests.
    Rendering
    Canvas 2D on a single animation loop, capped at thirty frames a second, device pixel ratio capped at two.
    Motion
    Paused off-screen, paused in a hidden tab, and paused when the system asks for reduced motion. Every plate can be stopped by hand.
    Assets
    None. Every image on this page is generated at runtime from a seed.
    Files
    index.html, assets/style.css, assets/studies.js, assets/app.js
    Keys
    Tab to a plate, Enter to open it, ← → to move between plates, Esc to close.
