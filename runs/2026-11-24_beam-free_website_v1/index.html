01 · Statement

Colour is a distraction. Grey is a decision.

Every image here was made with a single constraint: no hue. No warmth, no coolness, no accent to lean on. Just value — the slow negotiation between light and its absence.

The work is not about what is removed. It is about what remains when everything unnecessary is taken away: structure, rhythm, weight, silence. Eight studies. Three rooms. One spectrum, walked slowly.

— Mara Voss, curator

03 · Process

How a study is made

A small generative engine, written in plain canvas. No libraries. Regenerate to see a new composition.

The method

  1. Seed A deterministic seed drives every decision, so a composition can be reproduced.
  2. Layers Grayscale planes are stacked with varying opacity to build depth.
  3. Texture A noise field is thresholded into a dithered grain.
  4. Restraint Nothing is added that does not earn its place.
seed → layers → noise → threshold → compose

04 · Colophon

Colophon

SHADES is a fictional exhibition site built as a monochrome showcase. All imagery is generated: inline SVG for the gallery works, canvas for the hero field and the process engine. No external assets.

Type
System serif for display, system sans for body.
Palette
Black, white and the greys between. Nothing else.
Motion
Respects prefers-reduced-motion. Animations pause when off-screen.
Access
Keyboard navigable, skip link, focus rings, semantic landmarks, ARIA labels.
Tech
Plain HTML, CSS and JavaScript. No build step, no dependencies. GitHub Pages ready.

Built with restraint. If you are reading this, you are looking too closely — which is the point.
