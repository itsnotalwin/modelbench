01 / Selected works

Six seeded studies, drawn live.

No files, no photographs, no stock. Each piece is a small algorithm with a seed; re-run any of them to grow a new variant, or expand one to give it the whole wall.

02 / The halftone lab

One composition, many pressings.

A procedural still life, re-printed through a tunable halftone plate. Set the contrast, gamma, cell and pattern — then pull the PNG and keep it.

Pattern

Every pressing is deterministic: same seed, same plate, same image.

03 / Manifesto

Colour is a habit.

Value is a discipline.

Remove the habit,

and the discipline speaks.

MONO began as a wager between two designers: that a practice stripped of hue would see farther, not less. Five years later the wager holds. Black, white and the greys between carry all the weight we have ever needed — weight, edge, rhythm, rest. The machine draws; the human decides where to look.
