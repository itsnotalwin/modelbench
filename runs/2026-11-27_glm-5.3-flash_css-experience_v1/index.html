Keeper's notes

Close

Tank 07 is a self-contained exhibit. Three marine biomes, a day / dusk / night lighting rig, a feeding station, a current pump and a startle reflex — all driven by native HTML controls and CSS state. There is no JavaScript, no canvas and no video: every fish, jelly, bubble and light beam is styled DOM.

How it works, briefly:

  • A body:has() state engine reads the radios and checkboxes and re-themes the whole scene.
  • Fish are composed from individual transform channels — route, bob, facing and scatter live on separate layers so they never fight.
  • The tank scales with container queries (cqi / cqh), so every creature keeps its proportions at any width.
  • Masks, blend modes, clip-paths and gradient art draw the coral, caustics, glass and light shafts.
  • The keeper's panel itself opens with :target and enters via @starting-style.
  • Ambient motion honours prefers-reduced-motion, and the Calm switch pauses it on demand.

Daily routine: pick an exhibit, set the lighting, switch the pump on for a livelier current, open the feeding station and watch the tank rise to the surface. If a fish annoys you, the glass is very tappable.

Keyboard: Tab to travel, Space toggles, arrow keys change exhibit or lighting. This panel is plain CSS — it can't trap focus and Escape won't close it, so use the Close link. Species spotlighting responds to hover and keyboard focus.
