# ModelBench Project

## Purpose
A one-shot AI benchmark spanning web development, games, visual work and simulated worlds, explored through a full-stack Next.js lab. The twenty-two challenges span websites, applications, games, visual tools, simulations and worlds. Each model produces one finished artifact; the inbox importer routes ZIP packages into immutable runs.

## Current benchmark shape
Twenty-two standalone prompts in `prompts/`, 01-22. Prompts 01-20 are themed open briefs; 21 is a fixed subject (Floating Pagoda Island); 22 is a fixed source (refresh the live Shutterhaus Visuals site).

## Key entry points
- `src/app/` — Next.js App Router pages (explore, challenges, compare, leaderboard).
- `src/components/` — explorer, inspector, comparison, leaderboard and shell components.
- `src/data/catalog.json` — compact snapshot generated by `tools/sync_catalog.py`; the only catalog the UI imports.
- `src/db/` — Drizzle schema and pool for bookmark/score storage.
- `prompts/catalog.json` — canonical challenge catalog used by the importer.
- `prompts/*.md` — standalone challenge briefs.
- `public/briefs/` — the same briefs served to the explorer, regenerated by `tools/sync_catalog.py`.
- `public/art/` — original editorial cover artwork (WebP, two widths).
- `tools/sort_inbox.py` — safe ZIP intake, metadata validation, manifest and catalog rebuild.
- `tools/build_manifest.py` — generated `manifest.json`.
- `tools/sync_catalog.py` — manifest → `src/data/catalog.json` + `public/briefs/`.
- `.github/workflows/auto-sort.yml` — inbox automation.
- `legacy/static-dashboard/` — retired single-file dashboard and its PWA generator.

## Verify
`python -m unittest discover -s tests -p "test_sort_inbox.py" -v`, `python tools/build_manifest.py && python tools/sync_catalog.py`, then `npm exec tsc -- --noEmit` and `npm run build`. Keep prompts, catalog, explorer copy and importer validation aligned. Existing submissions are immutable; only an explicit organizer reset may clear runs.
